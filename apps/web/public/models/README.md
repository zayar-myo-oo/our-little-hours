# Characters

`manifest.json` lists the characters you can pick in Settings → Character.
Each entry needs a `.vrm` file in this folder (`file`), plus an optional preview image (`thumbnail`).

`.vroid` files are VRoid Studio projects and can't be loaded by the browser.
Open each one in VRoid Studio, use Export → VRM, and save it here under the name given in `file` (for example `girl-one.vrm`).
Characters without a `.vrm` file show as "Not exported yet".

Only use models you made yourself or have permission to use.
